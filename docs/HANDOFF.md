## 8. 알아두면 좋은 함정 (다음 작업 때 같은 실수 방지)

- Windows에서 파이썬으로 파일을 쓸 때 줄바꿈이 한 번 더 바뀜 → `newline=""` 또는 바이트로 쓰기
- PowerShell 5.1 스크립트에 한글이 있으면 UTF-8 **BOM**으로 저장해야 깨지지 않음
- API 주소는 `localhost` 대신 `127.0.0.1` (Windows에서 요청마다 2초 지연)
- Ollama는 입력이 한도를 넘으면 **에러 없이 자름** → `ollama/Modelfile`의 16k 모델 사용
- 추출기(`extractor.py`)는 원래 몇 분씩 걸림 → 멈춘 줄 알고 끄지 말 것
- `.env`는 인증정보 파일이라 Claude가 직접 열지 않음. LLM 연결 상태는 `/health`의 `llm_enabled`로 확인
- 자동 갱신 전 산출물 백업: `data/processed/backup_before_sync_20260929/` (git 제외)
