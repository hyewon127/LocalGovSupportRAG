# 데모 시나리오 (WBS 9)

직접 돌려보거나 시연 영상을 찍을 때 이 순서대로 따라 하면 됩니다. 아래 결과는 **2026-09-29에 실제 색인(청크 3,884개)과 로컬 LLM으로 돌려서 확인한 것**입니다.

## 0. 실행

```
scripts\start_chatbot.bat      (더블클릭해도 됨)
```
OpenSearch → 백엔드 → 화면 순서로 띄우고, 준비되면 브라우저에서 http://127.0.0.1:8501 을 엽니다.
처음에는 OpenSearch 샤드 복구와 임베딩 모델 로딩 때문에 1분 정도 걸립니다. 끌 때는 `scripts\stop_chatbot.bat`
(OpenSearch까지 끄려면 PowerShell에서 `scripts\stop_chatbot.ps1 -All`).

> **LLM:** 로컬 Ollama(`qwen2.5-rag:7b`)가 있으면 `[1]` 인용이 달린 답변이 나옵니다. 사이드바 "서비스 상태"에서 LLM 활성 여부를 볼 수 있습니다.
> 몇 분간 질문이 없다가 처음 묻는 질문은 모델을 GPU에 올리느라 20~30초 걸립니다(이후 5~10초). **시연 직전에 질문 하나를 미리 던져두세요.**
> LLM이 없으면 답변 문장 대신 "관련 공고 목록만 안내합니다"와 공고 카드가 나옵니다(status `llm_unavailable`). 고장이 아니라 설계된 동작입니다.

## 1. 기본 질문 - 슬롯 추출 + 하이브리드 검색

| 질문 | 확인 포인트 | 실측 결과 |
|---|---|---|
| 서울 소상공인 온라인 판로 지원사업 알려줘 | 답변 아래 "🔎 검색 조건" 줄에 지역·대상이 뽑혀 나오는지 | 지역=서울, 대상=소상공인 / `ok` 답변 |
| 여성기업 대상 수출 지원사업 있어? | 분야(수출)는 필터로, 대상(여성기업)은 검색어 힌트로 쓰이는지 | 분야=수출, 대상=여성기업 / "중소기업 수출지원사업 통합 공고" 등 |

공고 카드의 **상세 보기**를 누르면 공고 본문 청크를 순서대로 볼 수 있습니다(`GET /programs/{id}`).

## 2. 공고 제목과 다른 말로 묻기 - 의미 검색(kNN)의 역할

| 질문 | 실측 결과 |
|---|---|
| 실시간 방송으로 상품을 소개하면서 파는 걸 해보고 싶은데 촬영비를 지원받을 수 있나요? | "라이브커머스"라는 단어 없이도 "소상공인 온라인판로 지원사업", "TV홈쇼핑 및 데이터홈쇼핑 입점지원사업" 등을 찾음 |

설명 포인트: 이 질문에는 공고 제목의 단어가 거의 없어서 BM25(단어 일치)만으로는 못 찾습니다. 평가에서도 표현을 바꾸면
BM25 단독은 Hit@5가 37%로 떨어지고, 하이브리드는 88.9%를 유지했습니다([평가 리포트](evaluation_report.md)).

## 3. 관련 없는 질문 - 가드레일

| 질문 | 실측 결과 |
|---|---|
| 오늘 서울 날씨 어때? | `no_evidence` - "찾지 못했습니다" 안내, LLM 호출 없음 |
| 김치찌개 맛있게 끓이는 법 | `no_evidence` |

설명 포인트: "서울"이 들어 있어 지역 슬롯은 뽑히지만, 검색된 청크의 의미 유사도(kNN)가 임계값 0.77에 못 미쳐서
LLM을 부르기 전에 차단합니다. 근거 없이 지어낸 답을 원천적으로 막는 1차 장치입니다.

## 4. 한계도 보여주기 (면접용)

| 질문 | 실측 결과 | 원인 |
|---|---|---|
| 은퇴를 앞두고 회사를 자녀나 제3자에게 물려주고 싶은데 도움받을 수 있나요? | 상위 3건에 기업승계 공고가 나오지 않음(기술유출방지, 중장년 채용 등). "M&A나 기업승계 지원"처럼 단어를 넣어 물으면 정상 답변 | "승계"라는 단어가 질문에 없고, 임베딩이 청크 앞부분 약 250자만 반영하는 문제(README 7장) |
| 개인 주택담보대출 금리 알려줘 | 1차 가드레일(점수)은 통과하지만 **LLM이 "찾을 수 없다"고 거절** → 최종적으로는 올바르게 차단 | 기업 융자와 의미가 가까워 점수 하나로는 구분 불가. 2차 방어선(LLM + 인용 검사)이 막아준 사례 - 의도 분류를 넣으면 LLM 호출 전에 막을 수 있음 |

잘 되는 것만 보여주는 것보다, 실패 사례와 원인·개선 방향을 같이 설명하는 편이 설계를 이해하고 있다는 근거가 됩니다.

## 5. 로컬 LLM을 붙이며 겪은 일 (면접용)

"유료 API 없이 로컬 7B 모델로 출처 인용률 96.3%"까지 오는 과정 자체가 설명거리입니다. 자세한 수치는 [평가 리포트](evaluation_report.md) 5·7장.
1. 근거가 있는데도 "정보가 없다" → Ollama가 프롬프트의 65%를 **에러 없이** 잘라내고 있었음 (읽기 한도 4096)
2. LLM을 붙이자 오히려 검색이 나빠짐 → 7B 모델의 슬롯 추출이 틀린 필터를 만듦 → 로컬 모델에서는 끔
3. 인용률 48% → 내용은 맞았지만 `[번호]` 대신 사업명으로 출처를 밝힘 → 프롬프트에 형식 예시 한 개로 96.3%

## 6. API 직접 보기 (선택)

http://127.0.0.1:8000/docs 에서 `POST /chat`을 실행하면 화면 없이 응답 구조(`status`, `answer`, `sources`, `slots`)를 볼 수 있습니다.
